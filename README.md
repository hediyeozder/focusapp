# Focus App

Pomodoro timer and focus tracker for Android, built with Kotlin.

## Features
- Countdown timer (5-120 min) with pause/resume
- Stopwatch mode
- Session results saved locally with Room
- GitHub-style monthly calendar: darker squares for longer focus days
- Tap a day to see each session's start time and duration
- Month navigation, future days locked

## Tech
- Kotlin, Android SDK (min SDK 24)
- Room (SQLite) with coroutines
- RecyclerView + GridLayoutManager
- CountDownTimer, Handler
- Intents for navigation and data passing
